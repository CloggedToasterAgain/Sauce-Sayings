# Sauce Sayings API

## Overview

A super unofficial, super fan-made API dedicated to Taco Bell sauce packet sayings that is also super not affiliated with Taco Bell. Each saying entered with love and attention to the type of sauce.

## Features

Search our collection of sauces with all their sayings or ask for a random one!

## Endpoints
### /api/sayings/
This will return all sayings currently collected and available.

### /api/sayings/random
This will return a random saying of all sayings.

### /api/sayings/XX
This will return saying with id XX.
